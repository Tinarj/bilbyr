How does Gaussian noise affect the Stringy05 index?

A simulation study using four patterns and eight sample sizes

1 Introduction

This report investigates how the rescaled Stringy05 scagnostic changes when Gaussian noise is added to two-dimensional data. Stringy05 describes a geometric property of a scatterplot using a minimum spanning tree (MST). We want to learn how much noise the index can tolerate, whether its behaviour depends on the type of pattern, and whether results change with sample size.

The eventual goal is to design synthetic datasets with 500 observations for experiments in projection pursuit. The simulations here help us choose noise levels based on measured changes in Stringy05 rather than visual judgement alone.

In our rescaled index, 0 indicates that Stringy05 has reached its Gaussian-reference floor. It does not prove that there is no relationship between the variables. A positive value indicates that the index measures some Stringy structure above that floor.

2 Simulation setup

2.1 Four patterns

We study the following noise-free patterns:

  • Cubic: poly(t, degree = 3)[, 3], where t is drawn from a standard normal distribution.
  • Quartic: poly(t, degree = 4)[, 4], using the same type of input variable.
  • Sine: sin(pi * t), where t is standard normal.
  • Two moons: two interleaving semicircular arcs.

The cubic and quartic patterns use R’s orthogonal polynomial basis, rather than simply t^3 and t^4. For every pattern, the original X and Y coordinates are standardised separately to have mean 0 and sample standard deviation 1.

2.2 How noise was added

Noise was added independently to both X and Y:

\[ X_{i,\sigma,r}=X_{i,0}+\varepsilon_{x,i,\sigma,r},\qquad Y_{i,\sigma,r}=Y_{i,0}+\varepsilon_{y,i,\sigma,r}, \]

where both noise terms are drawn independently from \(N(0,\sigma^2)\).

Scagnostics describe bivariate scatterplots, so perturbing both coordinates is a useful symmetric way to investigate changes in their geometry. Adding noise only to Y would instead investigate a particular directional noise model. The noisy coordinates are not standardised again after adding noise.

2.3 Sample sizes, noise levels and repetitions

Setting Values
Patterns Cubic, quartic, sine, two moons
Sample sizes 100, 200, 300, 500, 750, 1000, 1500, 2000
Noise SD 20 equally spaced values from 0 to 1
Repetitions 100 per pattern, sample size and noise level
Base seed 1111
Index cassowaryr::sc_stringy05(..., rescale = TRUE)

There are \(4\times8\times20\times100=64{,}000\) planned index calculations.

For each combination of pattern and sample size, the original structure is generated once and kept fixed. Every repetition adds a new noise realisation to this same structure. Therefore, the differences between repetitions come from noise, not from a new sample of the original curve. At noise SD = 0, all 100 repetitions have the same data and score.

The original structure uses set.seed(1111). Noise repetition 1 uses seed 1112, repetition 2 uses 1113, and so on through 1211. The same repetition seed is used at each noise level, so noise realisations can be compared consistently across levels.

2.4 How the simulations were run

The simulations were run using an R script and a Bash launcher in the terminal. This example runs the quartic pattern at sample size 100, with 100 repetitions at 20 noise levels:

bash experiments/stringy_index/stringy_noise.sh \
  quartic \
  100 \
  1 \
  100 \
  1111 \
  experiments/stringy_index/results/quartic_n100.csv \
  "$(Rscript -e 'cat(paste(seq(0, 1, length.out = 20), collapse = ","))')"

Each completed Stringy05 result was appended to a CSV file. The output records the pattern, sample size, noise SD, repetition, noise seed and score. With the generating code and seed, the original structure and each noisy point cloud can be recreated without storing every noisy dataset.

4 What do the original patterns look like?

Code 
make_structure <- function(pattern, n, seed = 1111) {
  set.seed(seed)

  if (pattern == "two_moons") {
    group <- sample(rep(1:2, length.out = n))
    theta <- runif(n, 0, pi)
    x <- ifelse(group == 1, cos(theta), 1 - cos(theta))
    y <- ifelse(group == 1, sin(theta), 0.5 - sin(theta))
  } else {
    t <- rnorm(n, 0, 1)
    x <- t

    if (pattern == "cubic")   y <- poly(t, degree = 3)[, 3]
    if (pattern == "quartic") y <- poly(t, degree = 4)[, 4]
    if (pattern == "sine")    y <- sin(pi * t)
  }

  tibble(
    x = as.numeric(scale(x)),
    y = as.numeric(scale(y))
  )
}

original_patterns <- purrr::map_dfr(patterns, function(p) {
  make_structure(p, visual_n, base_seed) |>
    mutate(pattern = p)
})

5 How does each pattern change as noise increases?

We first focus on sample size 500, since this is the intended size of the final benchmark datasets. We show six noise levels spanning the experiment, including no noise and SD = 1.

At each level, we select the repetition whose Stringy05 score is closest to the median score across repetitions. We then recreate its X/Y coordinates using its saved seed. The label reports the mean Stringy05 over all 100 repetitions, not the score of the pictured repetition.

Code 
# Choose six positions from the 20-level noise grid
display_sd <- noise_levels[c(1, 2, 4, 7, 12, 20)]

selected_runs <- all_results |>
  filter(n == visual_n) |>
  filter(round(noise_sd * 19) %in% round(display_sd * 19)) |>
  group_by(pattern, noise_sd) |>
  mutate(distance = abs(stringy - median(stringy))) |>
  slice_min(distance, n = 1, with_ties = FALSE) |>
  ungroup() |>
  left_join(
    summary_results |>
      filter(n == visual_n) |>
      select(pattern, noise_sd, mean_stringy),
    by = c("pattern", "noise_sd")
  )

# Recreate only the small number of datasets needed for the figure
plot_data <- purrr::pmap_dfr(
  selected_runs,
  function(pattern, n, noise_sd, repetition, seed, stringy,
           distance, mean_stringy, ...) {
    original <- make_structure(pattern, n, base_seed)
    set.seed(seed)
    noise_x <- rnorm(n, 0, noise_sd)
    noise_y <- rnorm(n, 0, noise_sd)

    tibble(
      pattern = pattern,
      noise_sd = noise_sd,
      mean_stringy = mean_stringy,
      x = original$x + noise_x,
      y = original$y + noise_y
    )
  }
)

# Data for printing mean values in the panels
panel_means <- plot_data |>
  distinct(pattern, noise_sd, mean_stringy)

7.2.1 Interpretation of results

The simulation results show that the rescaled Stringy05 index is sensitive to increasing Gaussian noise, although the rate of decline differs across geometric patterns and sample sizes. Cubic and quartic patterns generally retain higher Stringy05 scores over a wider range of noise levels, while sine and two-moons patterns show a more rapid decrease. This suggests that the response of Stringy05 to noise depends on the underlying geometric structure.

Sample size also influences the behaviour of the index. In general, larger samples retain higher Stringy05 scores under the same noise conditions, particularly for cubic and quartic patterns. However, this relationship is not uniform across all patterns and noise levels. The distributions across repetitions further show that noise introduces variability in the index, with scores approaching zero as the noise level increases.

The heatmaps support these observations by showing how Stringy05 changes jointly with sample size and noise. In particular, they reveal that the transition from high to low Stringy05 scores occurs at different noise levels depending on the pattern. Therefore, the same amount of Gaussian noise does not necessarily produce the same reduction in Stringy05 across different geometric structures.

7.2.2 Conclusion

This study investigated the sensitivity of the rescaled Stringy05 index to Gaussian noise across four geometric patterns and eight sample sizes. The results indicate that Stringy05 generally decreases as noise increases, but its robustness varies considerably across patterns. Cubic and quartic structures retain higher index values under moderate noise, whereas sine and two-moons structures are more sensitive to perturbation. Larger sample sizes generally improve the persistence of the index, although the effect is pattern-dependent.

These findings highlight the importance of considering both geometric structure and sample size when evaluating the noise sensitivity of Stringy05. For future projection pursuit experiments, noise levels should be selected separately for each pattern rather than applying a single noise threshold to all structures.

The next stage will focus on selecting suitable noise levels for synthetic datasets with 500 observations, using the observed Stringy05 responses to construct examples with different levels of difficulty.
